## 🎬 NOTAS PARA GRABAR EN SYNTHESIA

### Setup técnico:

**Avatar:** Elige uno profesional pero accesible (no muy robótico)

**Fondo:** Blanco limpio o gradiente suave (no distrae)

**Velocidad:** Normal-rápido (1.1x speed está bien)

**Voiceover:** Español latino (Colombia si aplica, o neutral)

**Música:** Fondo suave, no distrae. Synthesia tiene stock music.
